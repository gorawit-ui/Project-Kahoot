# TASK-08 — Question Chamber and Q20 Input Polish

## Objective
Make the active Player screen feel like a premium magical quiz chamber while preserving the approved castle world and keeping action controls unmistakably legible on mobile.

## Scope
- Improve only presentation styles for the choice-question card, prompt banner, choices, Q20 bonus heading, and Q20 inputs.
- Add restrained gold/ivory framing and focus states; retain navy surfaces for legibility.
- Keep all decorative content behind controls and non-interactive.

## Non-goals
- No changes to question content, timer behaviour, answer payloads, server checking, room state, score calculation, or Host controls.
- Do not add 3D, autoplay audio, continuous fireworks, new brand symbols, or a replacement background asset.

## QA
1. Choice buttons preserve their pressed, selected, and disabled states.
2. Q20 focus ring is visible without covering text or mobile keyboard input.
3. The card has readable contrast at 360px and reduced-motion remains safe.
